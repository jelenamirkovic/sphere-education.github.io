Overview

Lab exercise incorporating IPv6.

Assignment Instructions

Setup

1. On “My Deterlab”, use Experimentation > Begin an Experiment to begin a new testbed experiment.

  1. Use NS file: /share/education/TCPSYNFlood_USC_ISI/synflood.ns
  2. Check “Swap In Immediately” or else remember to manually swap in the experiment after it is “created”. If you have trouble allocating enough nodes, keep trying; this is a busy time of the semester for Deterlab.
  3. Make sure to manually swap out your experiment when finished so you will swiftly release the class’ Deterlab resources for others to use.
  4. Submit screenshots of major steps below, and explanations of how link-local and how global addresses are formed; via Canvas.
  5. Use the link-local and global addresses from your experiment; they will likely be different from the ones below.

Tasks

1. Log in and SSH to router, server and client then become root (Note: the attacker node is left over from another exercise that used this NS file. We will ignore Attacker node for this exercise although it is an additional node that you can log into and further explore IPv6 configuration.)

2. Become root on router, client and server nodes:

sudo su -
3. Run “ifconfig” on router, client and server nodes to see the Link-Local addresses. 
ifconfig

Explain how these link-local addresses were formed. Add screenshots from router, client and server.

4. Verify that IPv6 kernel is running on the router, client and server nodes. 
test -f /proc/net/if_inet6 && echo "Running kernel is IPv6 ready"
5. Create /etc/radvd.conf file on router, client and server nodes to include script for each interface. Copy the script below (4.1.1 Simple configuration found at http://tldp.org/HOWTO/html_single/Linux+IPv6-HOWTO/#hints-daemons-radvd).

Note: remember the router has two interfaces; replace ethx and ethy below with the correct ethernet interfaces from your experiment!

interface ethx { 
    AdvSendAdvert on;
    MinRtrAdvInterval 3; 
    MaxRtrAdvInterval 10;
    prefix 2001:0db8:0100:f101::/64 { 
        AdvOnLink on; 
        AdvAutonomous on; 
        AdvRouterAddr on; 
    };
};
interface ethy { 
    AdvSendAdvert on;
    MinRtrAdvInterval 3; 
    MaxRtrAdvInterval 10;
    prefix 2001:0db8:0100:f102::/64 { 
        AdvOnLink on; 
        AdvAutonomous on; 
        AdvRouterAddr on; 
    };
};
6. Install neighbor discovery module (radvd) on router.

Note: it doesn't need to be installed on client and server nodes.

apt update
apt install radvd
7. After installing the radvd module, run neighbor discovery module on router. 
radvd

Explain what is the purpose of radvd.

8. Run “ifconfig” on router, client and server to see the Global addresses added. 
ifconfig

Explain how these addresses were formed. Include screenshots from router, client and server.

9. Ping the router from client and server using the link-local addresses. 
ping6 -I ethx -c 1 fe80::/64 (use the addresses from your experiment)
10. Run Neighbor Discovery from router to see the link-local addresses of client and server. 
ip -6 neigh show

Include screenshots from router, client and server.

11. Verify that IPv6 addresses are configured on router, client and server. 
/sbin/ip -6 route show dev ethx
12. Add router node as Gateway to client and server nodes. 
/sbin/route -A inet6 add default gw 2001:db8:100:f101::/64
13. Configure your “router” node as a IPv6 router.

Edit /etc/sysctl.conf and uncomment the line which contains net.ipv6.conf.default.forwarding=1 or add the line if you don't find it.
This is a common step to enable IPv6 routing, check https://wiki.ubuntu.com/IPv6#Configure_your_Ubuntu_box_as_a_IPv6_router.

14. Force Linux to reload the new configuration in /etc/sysctl.conf by executing the following command on router node: 
sysctl -p
15. Show the IPv6 network route from client and server. 
/sbin/route -A inet6

Include screenshots from client and server.

16. Ping both interfaces of the router from client and server using the Global addresses. 
ping6 2001:0db8:0100:f101::/64 (use the full global scope address from your experiment)
17. Run Neighbor Discovery from router to see the link-local and global addresses of client and server. 
ip -6 neigh show

Include screenshot from router.

18. Run debugging program on router to observe sent or received advertisements. 
radvdump > radvdump.txt
